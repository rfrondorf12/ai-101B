Adobe Certified Professional: Photoshop & Graphic Design

Source: adobe_professional_certificate.md

🗂️ Linked Flashcards

1. Exam Structure & Environment

Note: This introductory section covers testing logistics and is excluded from the flashcard deck per source instructions.

  • Exam Structure - Total time is 50 minutes to complete 13 multiple choice questions (Segment 1) followed by 17 live hands-on tasks in Photoshop (Segment 2).
  • Multiple Choice Segment - Consists of 13 questions; typically single choice unless specified otherwise.
  • Mark for Review - Checkbox available on any question or task to flag it with an icon, allowing you to return via the summary screen before final submission.
  • Reset Option - Any question or task can be reset to its initial state at any point.
  • Live Task Segment - Runs directly inside Photoshop with the certification test panel docked on the right and the document workspace on the left.
  • Workspace Reset - Reset interface layout via Window > Workspace > Reset the Certification Test Workspace.
  • Recommended Panel Layout - Dock the Layers and Properties panels right beside the certification test panel and keep them visible.
  • Blocked Features - The Help menu is intentionally blocked during the exam.
  • Exhibit Button - On select tasks, click Exhibit to preview the target visual result (before and after) before reading instructions.
  • Text Copy Shortcut - Any text styled in underlined, bold, and italic in the instructions copies automatically to the clipboard when clicked.
  • Exam Golden Rule - Only modify settings explicitly requested; leave all other dialog box options at their default values.
  • Passing Score - Requires 700 / 1000 points (70%). Score reports appear immediately upon submitting.

2. Identify Purpose and Audience

  • Purpose - The client's business goals and what they want to achieve with the design or image. Clarified through the design brief and direct client consultation.
  • Target Audience - The specific demographic group for whom the design is created (e.g. high school students aged 15–17).
  • Audience Age Considerations - Older and mature audiences can comprehend complex graphics, detailed infographics, and statistics; younger audiences require simpler layouts, vibrant colors, and characters.
  • Designer Brief Clarifications - Key questions to ask if a brief lacks detail:
    • What is the main message to convey?
    • What specific action should the viewer take after seeing the design?
    • How will the image be displayed (small handheld print vs. large classroom wall poster)?
  • Print Specifications - Specified in the brief: print dimensions, color mode, and resolution (300 ppi).

3. Requirements: Video, Print, and Web

  • Deliverables - The actual completed files supplied to the client at project delivery, determined by the medium (print, web, video). New document setup: File > New.
  • Print Requirements:
    • Resolution - Default suggested standard is 300 ppi (pixels per inch).
    • Color Mode - Work in RGB mode within Photoshop for full feature and tool availability; output/convert to CMYK for print production.
    • CMYK - Four-color process inks: Cyan, Magenta, Yellow, and Key color (Black).
    • Print File Formats - PDF, TIFF, and EPS.
    • Bleed Configuration - Set via File > Print > under Printing Marks enable Corner Crop Marks > open Functions > set Bleed (standard: 3 mm).
  • Web Requirements:
    • Resolution - Suggested standard is 72 ppi.
    • Color Mode - RGB color mode.
    • Export Paths - Export files via File > Export > Export As or File > Export > Save for Web.
    • Web Formats - JPEG, PNG, GIF, and modern WebP (accessible via File > Save a Copy > on your computer).
    • Compression Priority - Minimize file size for faster page load times without compromising visual image quality.
  • Film & Video Requirements:
    • Presets & Dimensions - Full HD / 1080p (1920 × 1080 pixels), 720p, and 4K UHDTV (3840 × 2160 pixels).
    • Pixel Aspect Ratio - Ratio between width and height of an individual pixel. Modern formats use square pixels (1.0 ratio); NTSC requires a 0.91 ratio; Anamorphic format uses a 2:1 ratio (rectangular pixels).
  • Image Classifications:
    • Raster Image - Pixel-based image, resolution-dependent; degrades and pixelates when scaled upward.
    • Vector Image - Mathematically calculated artwork; resolution-independent; scales infinitely without losing sharpness.

4. Key Components of Project Communication

  • Three Communication Pillars - 1. Project scope, 2. Due dates, 3. Possible impacts of delays.
  • Project Scope - Documented agreement defining deliverables, goals, and client expectations established in the brief.
  • Scope Creep - The gradual, unapproved expansion of project goals, deliverables, or revisions beyond the original agreement without adjustments to timeline, budget, or contract.
  • Preventing Scope Creep - Establish clear written deliverables, signed contracts, and explicitly limit allowed revision rounds included in initial pricing.
  • Change Order - A signed contractual amendment between designer and client detailing additional changes, altered directions, and compensation outside the initial scope.
  • Gantt Chart - Visual timeline representation for tracking project tasks, durations, overlaps, and deadlines.
  • Critical Path Method (CPM) - Visual planning technique identifying the sequence of dependent tasks that directly impact project completion date.
  • Feedback Loop - The cyclic process of a designer submitting work, the client reviewing and returning feedback, and the designer making revisions. Tracked via version numbers (v1, v2) and dedicated project subfolders.

5. Basic Project Management Concepts

  1. Planning and Analysis - Identifying target audience, demographics, client goals/purpose, securing contracts/agreements, and reviewing the design brief.
  2. Scheduling - Establishing realistic timelines based on deliverables and scope; setting deadlines with Gantt charts.
  3. Building - Asset creation and ideation (mind mapping, rough sketches, UI wireframing), prototyping, and developing final designs.
  4. Review and Evaluation - Internal peer reviews against the brief, formal client presentations (PDF/slides rehearsal), and client approval.
  5. Implementation and Publication - Delivering the completed final product in the format and medium for which it was designed.

6. Copyright, Permissions, and Licensing

  • Copyright - Automatic legal protection granting creators exclusive ownership over original works (designs, logos, illustrations) upon creation. Rule: "If you made it you own it; if someone else made it you need permission."
  • Public Domain - Creative material not protected by intellectual property laws (copyright, trademark, patent); owned by the general public and free for anyone to use without permission.
  • Derivative Work - New work altered from or based upon an existing original piece. Modifying a design does not make it yours; the original creator retains copyright and legal permission is required.
  • Fair Use - Legal doctrine allowing limited use of copyrighted material without permission in specific contexts: education, commentary, news reporting, and parody.
  • Four Fair Use Factors - 1. Purpose of use, 2. Nature of original work (factual vs. creative), 3. Amount used relative to whole, 4. Effect on the market/financial value for the copyright holder.
  • Licensing - Legal agreement permitting use of copyrighted material for a specified fee, timeframe, and defined usage terms.
  • Creative Commons (CC) - Licensing framework allowing creators to share work publicly while reserving specific rights ("some rights reserved").
  • Model Release - Signed legal document required when an individual person is recognizable in artwork.
  • Location Release - Signed legal document required when private property or recognizable commercial landmarks appear in artwork.

7. File Formats & Technical Attributes

  • Graphic Design File Categories:
    • Working / Project Files - PSD (Photoshop), AI (Illustrator), INDD (InDesign).
    • Asset Files - Raster/vector graphics, text files, spreadsheets.
    • Print-Ready Files - PDF, EPS.
  • Raster Image Formats:
    • JPEG - Lossy compression; produces compression artifacts at lower quality settings; supports embedded color profiles.
    • PNG - Lossless compression with transparency. Default 24-bit depth; PNG-8 provides 8-bit depth (2^8 = 256 colors) for smaller file sizes.
    • GIF - Supports frame animation; capped strictly at 8-bit depth (256 colors max).
    • WebP - Modern web image format offering efficient compression.
  • Bit Depth - Measurement of color data capacity per pixel (8-bit = 256 colors; 24-bit = 8 bits per channel RGB for 16.7 million colors).
  • Vector File Formats:
    • EPS - Vector format standard for print production.
    • SVG - Scalable Vector Graphics, standard for web deployment.
  • Camera RAW - Unprocessed sensor data from digital cameras; preserves wide tonal latitude for highlight and shadow recovery without clipping.
  • Tonal Range - Span between the darkest shadows and brightest highlights in an image.
  • Histogram - Graphical distribution of pixels from pure black (left), mid-tones (center), to pure white (right). Spikes on either far edge indicate clipping.
  • Access Full File Types - Access comprehensive export formats via File > Save a Copy.

8. Aliasing and Image Scaling

  • Aliasing - Jagged, stair-stepped pixel edges visible along curves and diagonals on low-resolution type or raster graphics.
  • Anti-Aliasing - Edge-smoothing technique that blends pixel colors with surrounding background to soften stair-stepping. (Note: Perfectly horizontal and vertical lines align cleanly to the pixel grid and do not require anti-aliasing).
  • Neural SuperZoom - Photoshop AI neural filter (Filter > Neural Filters) powered by Adobe Sensei to upscale raster images up to 9x while reconstructing missing details and reducing noise.

9. Color Spaces, Gamuts, and Calibration

  • Color Management - Systematic calibration ensuring color consistency from screen preview to final printed product.
  • ICC Color Profile - International Color Consortium (1993) standard describing device color space, gamut, and calibration parameters.
  • Color Models:
    • RGB - Additive color model for screens; combining red, green, and blue creates white (maximum intensity).
    • CMYK - Subtractive color model for print; combining inks creates dark/black tones.
  • Color Gamut - The complete range of colors reproducible within a color space. Relative gamut range:
    sRGB < standard CMYK < Adobe RGB < ProPhoto RGB
    • sRGB - Smallest gamut, standard for web and digital displays.
    • Adobe RGB - Wide gamut standard for graphic design and prepress print workflows.
    • ProPhoto RGB - Extra-large gamut used in professional photographic workflows.
  • Out of Gamut Warning - Warning indicator in Photoshop Color Picker alerting that a chosen color cannot be reproduced in CMYK print ink. Clicking the icon shifts to the nearest printable CMYK color.

10. LAB Color Space and Synchronizing Settings

  • LAB Color Mode (L*a*b*) - Three-dimensional device-independent color model matching human vision:
    • L (Lightness / Luminosity) - Measured on a scale from 0 (black) to 100 (white).
    • a-axis - Green (negative values) to Red (positive values).
    • b-axis - Blue (negative values) to Yellow (positive values).
  • Synchronizing Adobe Color Settings - Configure policies in Edit > Color Settings in Photoshop. To synchronize across Photoshop, Illustrator, and InDesign: launch Adobe Bridge (File > Browse in Bridge), navigate to Edit > Color Settings, choose your saved preset, and click Apply.

11. Photographic & Composition Principles

  • Aspect Ratio - Proportional relationship between image width and height (16:9 widescreen, 4:3 traditional, 1:1 square). Set via the Crop Tool.
  • Rule of Thirds - Compositional framework dividing the frame into 3×3 equal sections. Important visual focal points are aligned along grid lines or intersections rather than centered.
  • Planes of Depth:
    • Foreground - Visual elements positioned closest to the viewer.
    • Mid-ground - Intermediate visual space between foreground and background.
    • Background - Distant scenic backdrop or elements furthest away.
  • Depth of Field - The range of distance in an image that appears acceptably sharp:
    • Wide Depth of Field - Entire scene from foreground to background is in focus.
    • Shallow Depth of Field - Narrow plane of focus with blurred foreground and background to isolate the subject.
  • Contrast - Differentiation created through tonal or color variation to make key elements pop.
  • White Balance - Color temperature adjustment ensuring whites and neutral grays appear true without unnatural tint casts. Quick path: Image > Auto Color; manual Camera Raw path: Filter > Camera Raw Filter > Color.

12. Guides, Rulers, and Grids

  • Rulers - Toggle visibility via Cmd/Ctrl + R, View > Rulers, or Properties panel. Right-click ruler to change units (pixels, inches, cm). Drag top-left intersection to reposition the zero origin; double-click intersection to reset origin.
  • Creating Guides - Drag from horizontal or vertical rulers. Hold Alt/Option while dragging to toggle between horizontal and vertical orientation.
  • New Guide Commands - Create individual guide via View > Guides > New Guide. Generate multi-column/row grids with gutters and margins via View > Guides > New Guide Layout.
  • Manipulating Guides - Must use the Move Tool (shortcut: V). Highlighted guides delete with Backspace. Lock guides via View > Guides > Lock Guides.
  • Smart Guides - Dynamic magenta alignment guides showing alignment and spacing between objects (toggle: Cmd/Ctrl + Shift + R or View > Show > Smart Guides).
  • Grid - Toggle grid via View > Show > Grid.

13. Brushes, Presets, and Dynamics

  • Panels - Brushes panel (organizing, importing, presets) vs. Brush Settings panel (detailed dynamics and behavior).
  • Preset Libraries - Download Kyle T. Webster brush sets via Brushes panel menu > Get More Brushes or import via Import Brushes.
  • Brush Dynamic Parameters:
    • Size & Hardness - Brush diameter and edge softness (0% = soft edge, 100% = crisp edge).
    • Spacing - Distance between stamped tip instances (1% = continuous smooth stroke; larger values = dotted/spaced stamp pattern).
    • Scattering & Count - Disperses tip instances across axes and adjusts density.
    • Size & Angle Jitter - Randomizes size and rotational angle of brush stamps.
    • Transfer - Randomizes opacity per stamp.
    • Color Dynamics (Hue Jitter) - Randomizes stroke color between foreground and background hues.
    • Roundness & Angle - Compresses round tip into an oval and slants angle for calligraphy.
  • Lock Settings - Padlock icon locks customized settings across different brush tip shapes. Reset via Brush Settings panel menu > Reset All Locked Settings.
  • Exporting Brushes - Export customized brushes as .ABR files via Brushes panel menu > Export Selected Brushes.

14. Non-Destructive Editing Workflow

  • Core Philosophy - Workflow preserving original pixel and vector data so all edits remain reversible and re-editable at any point.
  • Four Pillars of Non-Destructive Editing - 1. Independent Layers, 2. Smart Objects & Smart Filters, 3. Adjustment Layers (with clipping masks), 4. Layer Masks.
  • Smart Objects - Protective container layers that keep embedded raster or vector source data intact at original resolution during transformations (scaling, rotation, skewing).
    • Convert layer via Right-click > Convert to Smart Object.
    • Double-click thumbnail to edit embedded child source document (extension .psb - Photoshop Big); save via File > Save to update master file.
    • Nested Smart Objects: Multiple layers or existing smart objects can be combined into a single master smart object.
  • Smart Filters - Any filter applied to a Smart Object layer automatically becomes a non-destructive Smart Filter with toggleable visibility, editable settings, and maskable areas.
  • Vector Layers - Text and Shape layers in Photoshop are native vector objects and scale infinitely without quality loss; converting to Smart Objects is unnecessary.
  • Layer Mask Toggle - Hold Shift and click layer mask thumbnail to temporarily disable/enable the mask.

15. Destructive Editing Operations

  • Definition - Irreversible changes that overwrite, alter, or delete underlying pixel data permanently once closed and saved.
  • Destructive Actions:
    • Flattening - Merging all layers into a single background layer via Layers panel menu > Flatten Image.
    • Rasterizing - Converting vector, text, or Smart Object layers into static pixels (Right-click > Rasterize Layer), forfeiting scalable vectors and live attributes.
    • Direct Painting - Painting directly onto existing image pixels with brush.
    • Direct Menu Adjustments - Applying adjustments via Image > Adjustments directly on raster pixels instead of using Adjustment Layers.
    • Direct Erasure - Erasing pixels with the Eraser tool instead of hiding them with a Layer Mask.
  • Non-Destructive Alternatives:
    • Eraser → Layer Mask (paint black to hide, white to reveal).
    • Direct Adjustments → Adjustment Layers with Clipping Mask (Alt/Option-click between layers).
    • Direct Painting → Paint on a newly created transparent layer above artwork.

16. Clone Stamp Tool and History Brush

  • Clone Stamp Tool (shortcut: S):
    • Samples pixels from a source point and replicates them onto a target area. Recommended hardness is 0% (soft brush).
    • Non-destructive workflow: Create a new blank layer above artwork, set Sample dropdown to All Layers, hold Alt/Option and click to sample source pixels, and paint on the blank layer.
    • Aligned Option - When enabled, sampling point moves synchronously with brush strokes. When disabled, every new stroke resets back to the initial sample anchor point.
    • Clone Source Panel (Window > Clone Source) - Allows scaling sample dimensions (e.g. 25%), flipping horizontally or vertically, and offsetting angles.
  • History Brush Tool - Paints pixel data back to a designated historical snapshot state selected in the History panel.

17. Character & Paragraph Typography

  • Character Formatting Options:
    • Tracking - Adjusts letter spacing uniformly across an entire word, sentence, or text block.
    • Kerning - Adjusts spacing between a specific pair of individual characters (shortcut: Alt/Option + Left/Right Arrow).
    • Baseline Shift - Offsets selected text vertically above or below the font's baseline.
    • Vertical & Horizontal Scale - Stretches glyphs vertically or horizontally (recommended to remain at 100%).
    • Ligatures - OpenType typographic feature joining adjacent character pairs (e.g. "Th", "fi") into a single unified glyph to improve legibility and aesthetics.
    • Discretionary Ligatures - Stylistic optional ligatures for specific decorative character pairs ("st", "ch").
  • Paragraph Formatting Options:
    • Alignment - Left, Center, Right, or Justified text alignment.
    • Indentation - Full paragraph margin indent or First-line indent.
    • Space Between Paragraphs - Adds vertical space between paragraphs cleanly without empty carriage returns.
    • Hyphenation - Toggles automatic word hyphenation across line breaks.

18. Export & Output Preparation

  • Document Verification:
    • Color Mode & Bit Depth - Verify via Image > Mode (RGB, CMYK, Grayscale, 8/16/32-bit).
    • Image Size & Resolution - Check via Image > Image Size (300 ppi for print). When Resample is unchecked, changing resolution preserves exact pixel dimensions and data while updating physical output size.
    • File Info Metadata - Access metadata via File > File Info > Basic category. Set Copyright Status to Copyrighted and add Copyright Notice.
  • Export Workflows:
    • Print Export - Save via File > Save As > choose Photoshop PDF > select PDF/X preset (e.g., PDF/X-1a, PDF/X-4).
    • Save for Web - Access via File > Export > Save for Web. Configure preset formats (JPEG, PNG, GIF), adjust quality slider, resize percentage, and click Save.
    • Export As - Access via File > Export > Export As. Select format, embed metadata/copyright, and add multiple output scale versions (e.g. 1x, 0.5x).
    • Render Video - Access via File > Export > Render Video. If video layers are present, select Adobe Media Encoder and MP4 format.

# Step 3: Task

**What goes in:** The context from step 2 and either a directly named file or pasted text.

**What this step does:**
1. Ask for a file name or text input
2. Read named file or text input provided
3. Adapt contents into note format
4. add note format as a note page in the HTML file
5. Adapt the contents into flashcard format
6. add flashcard file as a flashcard page in the HTML file.
7. Link created flashcards to note with a "linked flashcards" button on the notes page, and with a "linked note" button on the flashcard page
8. Assign the flashcards and notes to a subject folder based on content.

**Good looks like:** If the file teach_me_hub.html exists, a note page is generated, added to, and is accessible in the HTML file. A flashcard set for the note page is also generated, added, and is accessible in the HTML file. Both pages are linked to one another and included in an assigned subject folder based on the subject of the contents. 
The generated notes and flashcard sets follow the formatting directions from [[ai-101OB/project_02/02-context|02-context]] and include information only from the directly named file or supplied text from the "teach me (file name or pasted text)" prompt.

**How I check it:** the model tells me in plain language what it created, whether it only pulled information from the named file or text from the teach me prompt, where it pulled any additional information from and why with an option to keep or remove the information, and any issues or questions it has. I check if the HTML file exists and has been updated with new notes and flashcards and if it is accurate.

# learn-mode agent

## Role

Constructs and manages the interactive 3-tier Learn Mode deliverable from existing flashcards and notes, then commits and pushes updates to the private GitHub repository (`rfrondorf12/teach_me`) to deploy to Vercel.

## The step it replaces

**Step file replaced:** Advanced Study Synthesis / Learn Mode Step

**Why this step suits an agent:** It applies deterministic cognitive progression rules (pairing questions with internal deck distractors for Multiple Choice, isolating key vocabulary for Cloze completion, and formatting side-by-side recall containers) without hallucinating or introducing outside knowledge.

## Inputs it may read

- Generated HTML flashcard and note files in `/project_02/outputs/webpages/`
- Direct source note file or transcript from the original input
- `ai-101OB/project_02/02-context.md`

## What it does

1. Reads baseline flashcards and notes generated by `study-builder_agent`.
2. Builds **Tier 1 (Multiple Choice)**: Pairs flashcard questions with 3 distractors sampled strictly from other cards within the same deck.
3. Builds **Tier 2 (Cloze Completion)**: Generates fill-in-the-blank prompts from key terms extracted from the notes.
4. Builds **Tier 3 (Active Recall)**: Formats an open response text box with a side-by-side reveal of the source note excerpt for student self-evaluation.
5. Injects automated term shuffling upon launch (Fisher-Yates) and a spaced repetition queue (re-inserting missed or unmastered terms 3-4 cards ahead until mastered).
6. Applies high-legibility system typography and renders the full Questions & Answers reference table on the page.
7. Commits and pushes updates to `rfrondorf12/teach_me` for Vercel deployment.

## What it may not decide

- Sourcing distractors, definitions, or questions from outside the existing deck and source notes.
- Automatically evaluating or grading the student's typed responses in Tier 3 (the student must retain self-assessment authority).
- Modifying the underlying note formatting or original flashcard sets generated by `study-builder_agent`.

## Human check

The agent stops after pushing to GitHub and provides the live Vercel URL. The student opens the live site and tests all 3 tiers of Learn Mode to verify that distractors come strictly from the deck, cloze prompts are clear, and the side-by-side recall functions as intended.

# Hard rules: Sage

1. **Teaching rule.** When I say I do not understand or when an issue arises with the source material, explain the issue clearly in plain language rather than guessing, assuming, or modifying the text independently.
2. **Strict fidelity.** Only include information, definitions, and flashcards that come directly from the supplied input material. Never import facts or explanations from outside the provided file.
3. **Format discipline.** Bold all vocabulary terms, highlight equations in green, format notes according to `02-context.md`, and name files strictly as `note_[filename].html`, `flashcards_[filename].html`, and `learn_[filename].html`.
4. **Learn Mode boundaries.** Multiple Choice distractors must be sampled strictly from within the deck. Active Recall must leave grading authority entirely to the student via side-by-side note comparison. Tiers must be spaced so that Tier 1 and Tier 2 for the same question never occur back-to-back.
5. **Human check verification.** After pushing to the private `teach_me` GitHub repository, stop and provide the live Vercel URL. Never consider the process complete until I have checked the live site for accessibility and accuracy.

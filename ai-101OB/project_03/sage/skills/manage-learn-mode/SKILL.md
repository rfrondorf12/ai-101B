# Manage learn mode

## Purpose

Encodes the interactive study synthesis step extending Project 2. It builds a graduated 2-tier cognitive ladder (Tier 1: Multiple Choice with within-deck distractors; Tier 2: Active Recall with side-by-side verification) on top of existing flashcards, deploying updates to Vercel via GitHub.

## Workflow

1. **Ingest baseline deck:** Read the existing HTML flashcard and note files generated by `build-study-notes`. Extract all prompt-answer pairs and corresponding note context excerpts.
2. **Generate tier components:**
   - **Tier 1 (Multiple Choice):** For each card, generate 3 plausible distractors sampled strictly from other cards within the same deck.
   - **Tier 2 (Active Recall):** Format an open-response input box paired with a side-by-side hidden reveal of the source note excerpt for student self-evaluation.
3. **Complex step: Interleaved spaced-repetition sequencing loop.** Build the progression queue by running an interleaving algorithm across all cards. Verify that for any given flashcard item, its Tier 1 (recognition) and Tier 2 (active recall) challenges are never presented back-to-back. The loop must enforce a minimum spacing interval (e.g., interleaving items across the deck) to prevent immediate short-term priming and ensure true spaced repetition.
4. **Deploy and log:** Integrate the Fisher-Yates shuffle logic and spaced queue into the interactive deliverable. Commit and push the updated files to `rfrondorf12/teach_me` for Vercel deployment, provide the live preview URL, and append a round entry to the designated AI use log.

## Operating rules

- **Hard rules:** Distractors must be sampled strictly from within the current deck (no external vocabulary or facts). The agent must never auto-grade Tier 2 responses—self-assessment authority remains entirely with the student.
- **Where it stops and asks:** Stops after pushing to GitHub to require the student to open the live Vercel URL and test that interleaving and self-reveal recall containers function properly.
- **What it logs:** Logs the target deck name, total cards sequenced, minimum interleaving distance enforced, GitHub commit hash, and deployment timestamp in the AI use log following the Project 2 format.

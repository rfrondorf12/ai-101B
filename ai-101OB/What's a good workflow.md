The folder is the workflow -> break down workflow into multiple docs.

Very large workflows work best with very small steps
- every step is small
	- Models run on a reward system, will get sidetracked with a long doc

Limits/human checks
- Did it run? are the files still there? Is it still private?
- Rules like "if you are unsure ask me"
- Don't touch anything else on my computer
- What stays my decision section
- explain everything to me in common english language, I'm not a programmer

Breaks
- log what happened in the AI use log
- decide what to change and why
- change a step file -> fix happens in directions, not a chat message
	- fix it yourself

Formatting of folder .mds:
00-start-here.md - rules, goal, step order
01: trigger/when it runs
02: context the model needs
03: task that the model does
04: output: what comes out
05: human check --> human step = different color
-> link markdown files in steps as cards on canvas in obsidian
keep language clear and concise
